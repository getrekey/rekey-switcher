# Rekey Switcher

Automatic keyboard layout switcher for Mac. Type `thank zou` with the wrong layout on, and Rekey turns it into `thank you` and switches the layout for you. English, Russian, German, French, Spanish and Italian.

What you type never leaves your Mac.

- Website: [getrekey.app](https://getrekey.app)
- Downloads: [Releases](https://github.com/getrekey/rekey-switcher/releases)
- Support: [getrekey.app/support](https://getrekey.app/support/)
